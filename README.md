# 📚 Análise e Projeto de Sistemas

Bem-vindo(a) ao meu repositório de estudos! 💻

Este espaço foi criado para reunir e organizar anotações teóricas sobre **Análise e Projeto de Sistemas**, explorando conceitos fundamentais de modelagem, planejamento e desenvolvimento de software.

Os materiais fazem parte dos meus estudos na disciplina de **Engenharia de Software II** e têm como objetivo facilitar a revisão dos conteúdos e conectar a teoria com a prática.
